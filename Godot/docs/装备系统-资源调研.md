
# 玛法岁月 16.0.10 — 人物装备美术资源与数据资产调研

- 调查范围（资源）：`D:\rpg\output\files`
- 调查范围（配置）：`D:\rpg\output\lua_ref_src\script\setting\`（必要时追溯到 `script\const1.lua` 与 `script\game\...`）
- 统计方式：PowerShell `Get-ChildItem -Recurse -File` + ripgrep 正则；所有结论均附 `文件:行号` 或文件名。
- 通用命名后缀：绝大多数自定义资源以 `_SMINAD` 结尾（作者/加密标记）；Lua 中的模型名通常不含扩展名，扩展名由运行时 `string.format` 补上。

### A\E 后缀的含义

- A\E 是**同一部件模型的 5 套贴图变体**（几何相同、配色不同），与披风的 1\5 构成一套。
- 代码中不是"玩家选颜色"，而是**按职业索引取用**：

```lua
local MapBody = {
    { "dx_nan_kuzi_5A_SMINAD", "dx_nan_kuzi_5B_SMINAD", "dx_nan_kuzi_5C_SMINAD",
      "dx_nan_kuzi_5D_SMINAD", "dx_nan_kuzi_5E_SMINAD" },   -- [1] 裤子
    { "dx_nan_xiezi_5A_SMINAD", ... },                      -- [2] 鞋子
    { "dx_nan_shoutao_5A_SMINAD", ... },                    -- [3] 手套
    { "dx_nan_yifu_5A_SMINAD", ... },                       -- [4] 衣服
    { "dx_pifeng_1_SMINAD", ... "dx_pifeng_5_SMINAD" }      -- [5] 披风
}
pNpc:SetUnitTexture(string.format("dx\%s.blp", MapBody[1][JobType]), 31)
```

  证据：`clsSettingManager.lua:287-323`（表定义）、`clsSettingManager.lua:326/331/336/341/346`（按 `JobType` 取第 N 个）。`JobType` 对应 ZS/FS/DS/GJ/CK。
- 因此 dx 是"边境巅峰雕像 / 冠军雕像"专用的一套换装贴图，**不与玩家装备系统共用**：`dx_` 前缀在全部 Lua 中只出现于 `clsSettingManager.lua`，25 处引用集中在同一函数。
- 其余 dx 文件（`dx_1`、`dx_fx_1`、`dx_wuqi_*`）在 Lua 中**未找到引用**。

- `grep "Mdx" ItemCfg.lua` → **0 条**；`grep "StrType" ItemCfg.lua` → **0 条**；`grep "string.format" ItemCfg.lua` → **0 条**。

### 4.3 图标路径与模型路径如何拼出

1. **图标**：`ItemCfg.Icon` 已是 `icon\<name>.blp` 完整相对路径，**直接使用，不再拼接**（2588/2588 条）。
   - 例外：技能图标在代码里拼 `replaceabletextures\commandbuttons\%s.blp`（clsMouseManager.lua:245、252）；宠物技能拼 `Icon\%s.blp`（clsMouseManager.lua:260）。
   - UI 拖拽图标时直接取 `pItem:GetCfg().Icon`（clsMouseManager.lua:238）。
2. **模型/贴图**：`ShapeCfg` 中一律是**裸名**，运行时按部件拼目录：
   - 武器主手：`string.format("wq\\%s.mdx", Cfg.Mdx)` — clsUnitHero.lua:1836，clsCompModelRole.lua:184
   - 武器副手：`string.format("wq\\%s.mdx", Cfg.ExMdx)` — clsUnitHero.lua:1844
   - 翅膀：`string.format("cb\\%s.mdx", Cfg.Mdx)` — clsUnitHero.lua:1822，clsCompModelRole.lua:171
   - 发型：`string.format("shape\\%s.mdx", Cfg.Mdx)` — clsUnitHero.lua:1754，clsCompModelRole.lua:52
   - 衣/裤/鞋/手套：`string.format("rw\\%s.blp", Path)`，`Path` 按性别取 `Cfg.Path1/Path2` — clsUnitHero.lua:1783/1790/1797/1804
   - 披风：`string.format("rw\\%s.blp", Cfg.Path)` — clsUnitHero.lua:1811
   - 强化/星级贴图直接给全路径（`jn\...`），见第 7 节
3. **物品→外观的桥**：`clsItemEquip:GetShowShape()` 返回 `Cfg.Shape`（可被换形 `m_ChangeShape` 覆盖），见 clsItemEquip.lua:213-222；调用方 `clsUnitHero:UpdateEquipLook()` → `_ChangeShape(ItemType, ShapeId, StrongLv, BlessLv)`（clsUnitHero.lua:1706-1723）。

## 5. 人物（英雄）本体模型在哪 + 所有路径拼接模式

### 5.1 本体模型 = rw\ 目录

- 男女通用裸体基础模型：`rw\rw_nan_SMINAD.mdx`、`rw\rw_nv_SMINAD.mdx`
  - `UnitCfg_1.lua:1685-1692`：`[1747990106] Path = "rw\\rw_nan_SMINAD.mdl"`、`[1747990320] Path = "rw\\rw_nv_SMINAD.mdl"`
  - `clsUnitMonRole.lua:16,18`：`self:SetUnitModel("rw\\rw_nan_SMINAD.mdl")` / `("rw\\rw_nv_SMINAD.mdl")`
- 5 职业专用本体：`rw\rw_{nan,nv}_{zs,fs,ds,gj,ck}_SMINAD.mdx`（登录/选人界面用）
  - `clsRoleLoginView.lua:397-490`：`s_ShowModelPath[SEX_BOY][JOB_ZS].Path = "rw\\rw_nan_zs_SMINAD.mdx"` …（男女 × 5 职业共 10 条）
- 结论：**本体模型不在 wq/cb/shape，就在 rw\ 目录**；wq 是手上挂件，cb 是胸口挂件，shape 是头部挂件。
- 注意 Lua 中写的是 `.mdl`，磁盘上是 `.mdx`（War3 引擎按同名替换扩展名加载），Godot 侧统一按 `.mdx` 处理。

### 7.2 拼接规则（可直接实现的算法）

1. **解析链**：`ItemCfg[itemId].Shape` → `ShapeCfg[shapeId]`。`ShapeCfg` 的 `StrType` 决定部件：`WQ/YF/HS/KZ/XZ/PF/CB/FX`；映射表在 `const1.lua:814-822`（`SHAPE_STRTYPE2ITEMTYPE`，`FX→0`）。
2. **槽位**：装备栏位常量 `const.ROLE_EQUIP_POS_*`（const1.lua:730-750），类型→栏位 `const.EQUIP_TYPE2POS`（const1.lua:774 起）。
3. **贴图替换层（War3 SetUnitTexture 索引，务必照抄）**：

   | 部件 | 主体层 | 强化层 | 星级层 |
   |---|---|---|---|
   | 裤子 KZ | 31 | 36 | 44 |
   | 手套 HS | 32 | 37 | 45 |
   | 鞋子 XZ | 33 | 38 | 43 |
   | 衣服 YF | 34 | 39 | 46 |
   | 披风 PF | 35 | 40 | 47 |
   | 武器 WQ | — | 41 | 42 |
   | 发色 FX | 99 | — | — |

   证据：clsUnitHero.lua:1781-1815、1848-1856；同表见于 clsUnitNpc.lua、clsUnitMonRole.lua:125 起、clsCompModelRole.lua:130-164。
4. **性别分支**：`SEX_BOY(1)` 用 `Path1`，`SEX_GIRL(2)` 用 `Path2`；披风只有 `Path`，不分支（clsUnitHero.lua:1782/1789/1796/1803/1810）。
5. **挂点（attachment）**：
   - 武器：`HandState == 1` → `hand left`；`== 2` → 左右手各一个相同模型；`== 3` → 主手 `hand left` 用 `Mdx`、副手用 `ExMdx`；其他 → `hand right`。证据：clsUnitHero.lua:1837-1847（UI 版 clsCompModelRole.lua:185-195 的 2/3 分支左右相反，属原版差异，需自行取舍）。
   - 翅膀：`chest`（clsUnitHero.lua:1823）。
   - 发型：`head`（clsUnitHero.lua:1754）。
6. **强化/星级贴图查表**：`const.WEAPON_STRONG_PATH[JobType][EffLv]`（const1.lua:1083-1193）、`const.EQUIP_STAR_PATH[JobType][StarLv]`（const1.lua:1194-1304）；两级各只有 7 档，**第 8 档起全部复用第 7 档**（如 `wuqi_qh_zs7_SMINAD.blp` 在 [7]…[20] 重复 14 次）。取不到时回落到透明件：强化→`rw\rw_touming_SMINAD.blp`，星级→`rw\rw_touming2_<部件>_SMINAD.blp`（武器星级回落 `rw_touming_SMINAD.blp`）。
7. **未装备时**：`_OffEquipLook` 把 Shape 重置为裸装 ID —— 衣服 20 / 手套 30 / 裤子 40 / 鞋子 50 / 披风 60（clsUnitHero.lua:1863-1879）。
8. **Godot 落地建议**：把 `ShapeCfg` 预处理成 JSON（键：shapeId、strType、name、icon、mdx 或 path1/path2、handState、exMdx），把上述 7 个贴图层索引映射到 Godot 材质贴图槽（建议每部件一个 `ShaderMaterial`，`uniform sampler2D base/strong/star` 做透明度叠加），兵器/翅膀/发型用 `BoneAttachment3D` 挂到 `hand_left/hand_right/chest/head` 骨骼；`.blp` 需先转 PNG（DXT1/DXT5，注意 alpha）。
